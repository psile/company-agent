# 工位个人秘书

专属办公秘书的工作区，不是更弱的飞书 aily，也不是资讯客户端。

对外三个词：**专属、少扰、能记。**

一句话：按你的目标和作息守着；技术情报来了会判断「这件事此刻值不值得推给你」；你勾完成之后，把当天相关材料收成可回看的私人卡片。

本仓库是私有试点代码。桌面萌宠（EchoBot）只当形态外壳，办公规则写在 `secretary/`，情报与个性化推荐写在 `radar/`。

## 仓库结构

| 目录 | 做什么 |
|---|---|
| `docs/` | 产品方案计划书 |
| `secretary/` | W0 内核：目标、配额、完成即归档、升级门闩 |
| `radar/` | 技术情报 + 个性化推荐（同一条链路），GitHub 仓库也是这一份 |
| `RadarME/` | 早期静态界面，现已由 `radar/web` 接管 |
| `EchoBot-main/` | 桌面宠参考实现，不在这里改办公逻辑 |

## 情报与推荐（radar）

第 3 个功能（技术情报）和第 6 个功能（个性化推荐）共用一条链路，不是两套模块：

```text
外部信息采集
    → LLM 结构化理解（中文摘要 / tag / 价值）
    → Memory 取当前兴趣、项目、行为
    → 规则排序 + LLM 重排
    → 主动推送（中文总结 + tag）
    → 用户反馈
    → 更新 Memory
```

- **情报**：世界上发生了什么（时效、重要性、来源）
- **为你**：这件事对当前这个人、当前这个项目值不值得推
- 每条推送带中文总结和中文 tag，方便扫一眼决定感不感兴趣
- 有用 / 收藏升权并入库；不相关降权；忽略不等于讨厌
- 没有原文链接的条目不准进候选池

### 本机运行

```powershell
cd radar
python -m radar serve
```

浏览器打开 http://127.0.0.1:8765/

对外监听（本机当一台云 VM）：

```powershell
$env:RADAR_HOST="0.0.0.0"
$env:PORT="8766"
python -m radar serve
```

### 环境变量

| 变量 | 含义 |
|---|---|
| `LLM_BASE_URL` | OpenAI 兼容网关，如 `http://127.0.0.1:8000/v1` |
| `LLM_API_KEY` | 模型密钥，不要写进仓库 |
| `LLM_MODEL` | 模型名 |
| `FEISHU_WEBHOOK_URL` | 飞书自定义机器人；不配则只准备文案 |
| `RADAR_LLM=0` | 关掉模型，退回启发式 |
| `MEMORYOS_ENABLED=1` | 尝试接入官方 MemoryOS（需自行安装依赖） |

示例见 `radar/env.example`。

```powershell
cd radar
python -m pytest -q
```

## 秘书内核（secretary）

W0 只验证一件事：**设周/日目标 → 勾完成 → 预览确认后成卡 → 升到 Lv2。**

硬约束写在代码里：

- 周目标最多 3，日目标最多 3
- 工作日主动推送有配额；深度工作禁止弹窗
- 未完成、未确认、无 `source_url`，不准入库
- Lv3 才开关注源，Lv5 才开群提醒

明确不做：写 PPT、虚拟电脑、管项目、群监听、自动建库、陪聊推送。

