# 个性化推送：一条链路

价值一句话：先看世界上发生了什么，再判断哪些值得推给**此刻的这个人**。

```
采集 → LLM 理解 → Memory 取当前兴趣/项目/行为 → 排序 → 主动推送 → 反馈 → 更新 Memory
```

情报（功能 3）和为你（功能 6）共用候选池，不是两套模块。

当前是 **一个 Agent + 多用户**：管理员创建账号，用户登录后各自有一份私有 Memory、工作记忆（待办 / 提醒 / 日报）、推荐和知识库。所有 API 的 user_id 来自 session token，不信任前端传入。飞书 open_id 映射到同一个 internal user_id，Web / 飞书统一身份。详见 [AUTH.md](AUTH.md)。

办公 Skill（任务捕捉、拆解、智能提醒、今日重点、工作总结、项目跟踪）已接入对话；研究助手等仍为占位。提醒能解析「等下三点」这类中文时刻，到点推飞书和站内通知。

工作总结页是 Timeline-first：基于 Task、WorkEvent、Goal、Knowledge 等工作数据形成按日期组织的工作时间轴，每天一张简报卡（摘要 + 完成数 + 关键进展 + 决策 / 风险），完整日报、周报、月报按需展开，作为个人长期工作记忆的入口。

## 分工

| 层 | 做什么 |
|---|---|
| Collector | arXiv / GitHub Release / RSS / 指定 URL；去重；必须有原文链接 |
| Intelligence | 中文摘要、标签、创新点、重要性；不负责推不推 |
| Memory | 画像、带权兴趣、当前项目、行为与负反馈 |
| Recommender | 规则分（语义/兴趣/项目/时效/质量/反馈）+ LLM 重排 |
| Push | 中文总结 + tag + 为什么推给你；同一条不重复 |
| Feedback | 有用/收藏升权并入库；不相关降权；忽略不等于讨厌 |

## 卡片上必须有

- 中文总结
- 中文 tag（方便扫一眼）
- 为什么推给你
- 和当前项目的关系（有的话）
- 原文链接

## 本 Demo 不做

全网爬登录墙、推荐 Transformer、未授权的群监听、把内部文档丢给公网模型。
